# sari-client-data

مجلد ملفات بيانات. لا يوجد فيه كود تطبيق: لا ملفات Python أو Dart أو PHP أو مشروع تنفيذي داخل هذا المجلد. الملفات جداول وقياسات وملف مضغوط. صفوف البيانات لا تُنسخ هنا.

# الجزء الأول - التعريف والفهم العام

## 1. ما هو المشروع؟

مجموعة ملفات تدريب واختبار وتسليم لنموذج، بجانب ملف استهلاك كهربائي منزلي كبير داخل `uci`. الاستعمال الظاهر من الأسماء ومن أعمدة العناوين: سلاسل قراءات عدادات وعمود شذوذ في بعض الملفات.

## 2. لماذا يوجد هذا المشروع؟

وثيقة هدف مستقلة غير موجودة داخل هذا المجلد. استنتاج من أسماء الملفات والأعمدة: الملفات مادة لنموذج يتنبأ أو يسلّم عمود `anomaly`، وملف UCI مادة قراءات كهرباء منزلية. برنامج SARI في مجلد آخر يشير إلى مسارين افتراضيين داخل هذا المجلد، وذلك موثق في قسم التكامل كإحالة خارجية لا ككود هنا.

## 3. من يستخدمه؟

غير موثق داخل هذا المجلد. لا شاشات مستخدمين ولا أدوار.

## 4. ماذا يستطيع النظام أن يفعل؟

هذا المجلد لا يشغّل نظاما. الملفات المتاحة:

| الملف | الحجم التقريبي من فحص الملفات | ملاحظة |
|---|---|---|
| `train_.csv` | حوالي 57.7 مليون بايت | أكبر من عرض الصفوف هنا |
| `train_.xlsx` | حوالي 38.7 مليون بايت | مصنف بنفس اسم التدريب |
| `test_.csv` | حوالي 69.1 مليون بايت | |

## 12. التكامل بين الوحدات

داخل هذا المجلد لا توجد وحدات برمجية تتكامل.

إحالة خارجية، وليست كودا هنا: مجلد `Sari_app-main/live_model` يضبط مسارين افتراضيين:

- `SARI_CLIENT_TRAIN` يشير في الكود إلى `train_.csv` داخل هذا المجلد.
- `SARI_UCI_PATH` يشير في الكود إلى `uci/household_power_consumption.txt`.

## 13. المصطلحات

| المصطلح | المعنى من العناوين والأسماء |
|---|---|
| `anomaly` | عمود في التدريب وفي ملفات التسليم |
| `meter_reading` | عمود قراءة عداد في التدريب والاختبار |
| `building_id` | عمود معرف مبنى |
| `row_id` | عمود معرف صف في الاختبار والتسليم |
| LSTM | جزء من اسم ملف التسليم `final_LSTM_submission` |
| UCI | اسم المجلد والملف النصي للاستهلاك المنزلي |

تعريف رسمي لقيم `anomaly` (0 أو 1 أو غير ذلك) غير موثق من العناوين وحدها، وصفوف القيم لم تُنسخ.
